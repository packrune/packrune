# Code of Conduct

Packrune is built by humans for humans. We expect every participant — contributor,
maintainer, reviewer, user filing an issue — to follow a simple rule:

**Be respectful. Argue ideas, never people.**

## Concretely

- Disagree with the code, the design, the decision. Don't make it about the person.
- Assume good faith. People are usually trying to help, even when their tone slips.
- Hostility, harassment, slurs, doxxing, sustained personal attacks, sexualized
  language directed at someone — not welcome. Period.
- Off-topic political/religious flamewars belong elsewhere. Keep this space about
  Packrune.

## Enforcement

Maintainers may, at their discretion:

- Edit or delete offending comments.
- Close issues/PRs that violate this code.
- Temporarily or permanently ban contributors who repeat violations.

Report problems privately by opening a confidential issue or emailing the
maintainers (address in README once project is public).

This document is intentionally short. The longer a code of conduct gets, the more
people skip it. Read it once, then go write code.
